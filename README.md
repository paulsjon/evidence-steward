# Evidence Steward

An entry for the Cognizant [Open Agentic Web Challenge](https://cognizant-agenticweb.devpost.com/).

**Agents that ask on behalf of care discover agents that vouch for evidence.** No single source answers: each steward vouches only for what it is accountable for, the asking agent composes the answer, and the meaning of every claim travels with it.

Illustrative only. Not affiliated with any manufacturer. Built from public labels and published studies. Not medical advice. Jurisdiction rules are illustrative and pending legal review.

## Metformin Evidence Steward

- **Network address:** `https://paulsjon.github.io/evidence-steward/metformin_evidence_steward`
- **Agents:** one front agent, `evidence_steward`. The checks that must not depend on a model (dropped qualifiers, superseded claims, label status by market, freshness, digests) run in code, in `docs/js/ledger.js`.
- **Reads, shared with every site** through `docs/bridge/bridge-actions.js` because they return only public facts:
  - `get_steward_info`: who runs it, scope, principles, markets and their adverse event routes, correction route, today's date
  - `find_claims`: claims by topic or id, with their status for the asker's declared market
  - `check_draft`: checks a draft answer for dropped qualifiers, superseded claims, status, freshness and digests
- **Ledger:** `docs/js/claims-data.js` is the source of truth. `docs/claims.json` is the published copy with digests.
- **Approval:** every claim is pending approval by the steward approver until it is reviewed.

Other agent sites that call this network run it in their own visitor's browser, on that visitor's key, after a consent card. They get the three shared reads; the assistant points to this site's page for everything else.

### Files

```text
docs/
  index.html, styles.css, favicon.svg     the page
  js/claims-data.js                       the ledger (source of truth)
  js/ledger.js                            the steward's rules
  js/app.js                               renders the ledger
  site.js, site-actions.js                mounts the assistant and registers its reads
  metformin_evidence_steward.hocon        network source
  metformin_evidence_steward.network.json generated by the build; do not edit
  agent-manifest.json, links.json         public bundle files
  agent-mcp.json, .well-known/            generated discovery files
  bridge/                                 action bridge for other agent sites
  claims.json                             published ledger, generated
  runtime/                                browser runtime from the agentic-web repository, unchanged
  tests/                                  Node tests
tools/build_ledger.mjs                     writes docs/claims.json
question-desk/                             the Question Desk site (in progress)
wrangler.jsonc                             Cloudflare config for the Question Desk
```

### Build, test and serve

From the repo root, with the [agentic-web](https://github.com/cognizant-ai-labs/agentic-web) repository checked out next to it as `../agentic-web`:

```shell
node tools/build_ledger.mjs
node ../agentic-web/skills/agentify-website/scripts/build_network.mjs docs/metformin_evidence_steward.hocon --manifest docs/agent-manifest.json
(cd docs && node --test "tests/*.test.mjs")
node ../agentic-web/skills/agentify-website/scripts/serve_site.mjs docs --port 8080
```

### Privacy and keys

The assistant sends the visitor's messages, and the claims it reads, to the LLM provider the visitor picks in AI model settings. Do not enter patient details. To try your own key, use one with a low spending limit; afterwards select **Delete setup** under **Advanced settings (optional)** and close the tab.
