# Evidence Steward

An open agentic web entry for the Cognizant Open Agentic Web Challenge.

Two linked agentic websites:

- `docs/` — **Evidence Steward** (GitHub Pages): publishes versioned, human-approved evidence claims about metformin, with their qualifiers, and an agent network that vouches for them.
- `question-desk/` — **Question Desk** (Cloudflare Pages): an HCP-facing assistant that drafts answers from public sources and, with the visitor's consent, loads the Steward's agents to check the draft for lost context.

Illustrative only. Not affiliated with any manufacturer. Built from public label and registry data. Not medical advice.

Status: work in progress.
