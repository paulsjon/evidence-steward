How agents use this steward

  1. An assistant on another website drafts an answer for a clinician.
  2. With the visitor's consent, it loads this steward's agent network into the visitor's browser.
  3. The steward checks the draft in code: dropped qualifiers, superseded claims, label status for the clinician's market, freshness and digests.
  4. The answer goes back corrected, with a receipt listing every claim used.
